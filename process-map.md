---

| Step | Artefact | Uses | Produces |
|---|---|---|---|
| **FRAME** | `opportunity-frame.md` | Shared knowledge + strategic decisions + previous iteration outcome, if any | Current decision question and candidate scope |
| **INVESTIGATE** | `market-demand.md` | Opportunity frame | Demand, supply and keyword evidence |
|  | `competitors.md` | Opportunity frame + market evidence | Competitor, offer, review and customer-friction evidence |
|  | `product-economics.md` | Economics baseline + observed prices + production assumptions | Candidate-specific economics |
| **SYNTHESISE / REFINE** | `opportunity-assessment.md` | Investigation artefacts + shared baselines | Refined opportunity set |
| **COMPARE** | `product-comparison.md` | Opportunity assessment | Side-by-side comparison |
| **DECIDE** | `pilot-decision.md` | Product comparison | Selected pilot scope |
| **IMPLEMENT / PILOT** | `pilot-plan.md` | Pilot decision + shared baselines | Controlled market test |
| **MEASURE** | `measurement.md` | Live pilot | Observed buyer and commercial results |
| **LEARN** | `learning-review.md` | Measurement + original pilot hypotheses | Interpretation and lessons |
| **ITERATE / EXIT** | `iteration-outcome.md` | Learning review | Next iteration, operate/expand, pivot or stop |

If another discovery iteration is required:

```text
opportunity assessment
+ pilot decision
+ measurement
+ learning review
+ iteration outcome
        ↓
new opportunity frame
```

The next frame states the next business question. Shared platform, economics, channel and risk knowledge remains reusable across iterations.
