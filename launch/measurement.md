We measure only what changes a decision.

| Area | Measures |
|---|---|
| Discovery | Listing views, shop visits, Etsy-search traffic, favourites |
| Conversion | Orders, conversion rate, orders per listing |
| Commercial | Revenue, average order value, contribution after platform/payment costs |
| Product | Performance by family, single vs bundle |
| Production | Creation time, reusable assets, support time |
| Customer | Questions, reviews, requests and complaints |

## Interpretation

| Signal | Next investigation |
|---|---|
| Views but no sales | Product fit, listing presentation, price, buyer intent |
| Sales but weak contribution | Price, bundle, fees, production/support effort |
| Strong conversion but little traffic | Search terms, relevance, catalogue breadth |
| One family consistently stronger | Expand adjacent products/bundles |
| Repeated customer request | Feed into next FRAME |
| Little traffic + weak search evidence | Reject/deprioritise candidate |
