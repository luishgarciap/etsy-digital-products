## Purpose

The pilot converts research hypotheses into real buyer evidence.

The working starting point is **3–5 strong products**, with variants or bundles only where they test a specific hypothesis.

## Before pilot

Each product should have:

- a defined buyer/use case;
- Marketplace Insights evidence;
- competitor/review evidence;
- a clear proposition;
- a plausible price;
- basic unit economics;
- production/licensing/IP checks;
- a defined success/failure signal.

## Observation

A first review after roughly **30–45 days** is a practical starting point. Seasonality or low search volume may require a different period.

Paid Etsy Ads should not be the default first step. Etsy recommends optimising listings and observing buyer interest before relying on ads. [[24]](../references.md#ref-24)

## Fast iteration

After each pilot:

- **EXPAND** — strong evidence; create adjacent products/bundles
- **IMPROVE** — promising signal but execution issue
- **REPRICE / REPACKAGE** — demand exists but conversion/economics are weak
- **PAUSE** — insufficient evidence or lower priority
- **REJECT** — hypothesis not supported

## Exit from discovery

We leave the discovery loop when the main hypotheses around buyer, product, demand, economics and production have been **sufficiently validated or rejected** to make an operating decision.

Possible exits:

1. **Operate / expand selected product line(s)**
2. **Pivot to a different product family**
3. **Stop the Etsy experiment if no viable path remains**

The intended outcome is not endless testing; it is a product line worth operating.
