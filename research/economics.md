## Current Etsy cost structure

| Cost | Current rule |
|---|---|
| Shop set-up | One-time non-refundable fee; amount varies by location and is shown during set-up [[2]](../references.md#ref-2) |
| Listing | US$0.20 per listing; expires after four months [[2]](../references.md#ref-2) |
| Transaction | 6.5% of total order amount [[2]](../references.md#ref-2) |
| Etsy Payments — Brazil | 6.5% + US$0.30 per order [[3]](../references.md#ref-3) |
| Currency conversion | 2.5% when listing currency differs from payment-account currency [[5]](../references.md#ref-5) |
| Offsite Ads | 15% on attributed orders below US$10k threshold; 12% after threshold [[25]](../references.md#ref-25) |
| Etsy Ads | Optional; minimum US$1/day; new shops wait 15 days [[24]](../references.md#ref-24) |

Payoneer may add withdrawal/FX costs. [[4]](../references.md#ref-4)

## US$5 example

Ignoring taxes, Payoneer/FX, software, refunds and labour:

- Sale price: **US$5.00**
- Etsy transaction fee (6.5%): **−US$0.325**
- Brazil processing (6.5% + US$0.30): **−US$0.625**
- Listing/renewal allocation: **−US$0.20**
- Approximate remainder before other costs: **US$3.85**

If attributed to a 15% Offsite Ad, another US$0.75 would reduce the illustrative remainder to about **US$3.10**. [[2]](../references.md#ref-2) [[3]](../references.md#ref-3) [[25]](../references.md#ref-25)

This is contribution before other costs, **not net profit**.

## Price signals already observed

- `coffee menu`: typical price ~US$7. [[10]](../references.md#ref-10)
- `matcha menu`: ~US$6.85. [[11]](../references.md#ref-11)
- `spanish flashcards`: ~US$3.40. [[14]](../references.md#ref-14)
- `birthday invitations`: ~US$5.12. [[13]](../references.md#ref-13)

These price levels make production reuse, bundles and low support effort important.

MirthlyStudio's invitation bundles, games, signs and website products illustrate a product-family model that may raise order value beyond a single low-priced file. [[21]](../references.md#ref-21)
